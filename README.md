# CHAMBER · @COLT

나의 이야기와 기록을 위한 SF HUD 작업실입니다. 서버나 빌드 과정 없이 정적 파일로 실행합니다.

## 실행과 화면

`index.html`을 열거나 저장소 루트에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요. GitHub Pages는 기존과 같이 `main` 브랜치의 루트를 배포 대상으로 사용합니다.

- `#home`: 모듈 선택 홈. 청백색 포인트와 스코프 아이콘을 적용한 SF HUD 홈입니다.
- `#profile`: **SYS.PROFILE**. 기존 자기소개표 편집 화면과 모든 기능을 유지합니다.
- `#excerpt`: **TXT.EXTRACT**. 소설·채팅 발췌 이미지 편집기입니다.

각 편집기는 처음 열 때 불러옵니다. 홈이나 다른 탭으로 이동해도 편집기는 유지되므로 작업 내용이 사라지지 않습니다. 새로고침하면 초기화됩니다. 발췌기의 서식·배경·출력 규격은 현재 브라우저에 프리셋으로 보관합니다. 원문과 출처는 저장하지 않습니다.

## TXT.EXTRACT 사용 방법

1. 내용을 붙여넣으면 웹서식 없이 자동 분리됩니다. 직접 입력한 경우 **내용 적용**을 누르세요.
2. `*별표 지문*`, `**별표 지문**`은 지문, 큰따옴표·겹낫표·홑낫표는 대사, `인물명: 대사`는 인물별 대사로 분류합니다. 별표 지문은 여러 줄도 인식합니다.
3. 표시 없는 문장은 기본 분류를 **대사** 또는 **지문**으로 선택합니다. 문맥을 추론하는 AI 분류가 아니므로 문단 목록에서 분류·인물·내용을 직접 수정할 수 있습니다. 이름이 없는 대사의 인물은 직접 지정합니다.
4. 상단 도구 모음에서 소설형 또는 말풍선 채팅형을 선택합니다. **FONT** 탭에서 서식을 설정합니다. 지문 전체, 대사 전체, 인물별, 선택한 문단의 색·볼드·이탤릭·취소선·형광펜·말풍선 색과 위치를 바꿀 수 있습니다.
5. **내용** 탭의 선택 문단에서 글자를 드래그하면 부분 볼드·이탤릭·취소선·형광펜도 가능합니다. 부분 서식 → 문단 서식 → 인물 서식 → 지문/대사 기본 서식 순서로 우선합니다. 문단 내용을 수정하면 그 문단의 부분 서식이 초기화됩니다. 원문을 다시 적용하면 문단별 수정과 인물별 서식이 초기화됩니다.
6. 글자 크기, 줄 간격, 장평, 자간, 문단 간격, 지문·대사 추가 간격, 전체 여백을 조절합니다. 기본 크기는 12pt이며 SYS.PROFILE과 동일한 8개 글꼴 옵션을 제공합니다. WOFF/WOFF2/TTF/OTF 파일을 직접 등록할 수 있습니다.
7. **THEME** 탭에서 프로필과 동일한 8개 테마, 격자, 배경색, HUD 프레임 또는 첨부 이미지를 사용합니다. 기본 화면은 청백색이며 기존 테마 값은 유지합니다. 이미지의 불투명도와 밝기는 글자와 독립적으로 적용됩니다. 이미지 중앙을 기준으로 각 페이지를 채웁니다.
8. 제목과 제작자·캐릭터·플랫폼·출처는 각각 네 모서리 또는 숨김을 선택합니다. 본문 글꼴·크기·색상을 따르거나 별도 지정할 수 있습니다. 모든 페이지에 반복 표기되며 도구 이름·도메인·제작자 워터마크는 출력하지 않습니다.
9. 채팅 말풍선의 색상·SF/둥근 형상을 선택하고 인물별 이미지를 등록해 표시 여부를 설정합니다.
10. 컨트롤 패널의 **?** 버튼은 프로필과 같은 QUICK GUIDE 창을 엽니다. 번호형 사용법, 글꼴 크레딧, 라이선스 출처, 직접 등록 폰트 이용 책임 안내와 ACCESS 버튼이 있습니다.

### 페이지 나누기와 저장

- **자동 높이**: 내용 길이에 맞게 세로 길이를 계산합니다. 높이가 12,000px를 넘으면 여러 장으로 나눕니다.
- **지정 크기**: 너비·높이를 직접 지정하거나 1:1 / 4:5 / 9:16 / 16:9를 선택합니다. 넘치는 내용은 글줄 사이에서 다음 페이지로 이어집니다. 긴 문단과 말풍선은 여러 페이지에 이어질 수 있습니다.
- **4장 맞춤**: 글자 크기를 유지하면서 정확히 4장에 분배합니다. 지정한 높이를 최소 높이로 사용하고, 넘치면 네 장의 높이를 동일하게 늘립니다. 아주 짧은 내용에는 빈 본문 페이지가 포함될 수 있습니다. 네 장에도 담을 수 없는 경우 안내하며 내용을 잘라 버리지 않습니다.
- **PNG 저장**: 현재 페이지를 미리보기와 같은 크기의 PNG로 저장합니다.
- **전체 페이지 PNG 개별 저장**: 페이지 번호가 붙은 PNG를 한 장씩 다운로드합니다. 브라우저가 다중 다운로드를 차단하면 OUTPUT의 개별 파일 링크로 저장합니다.
- **사용자 프리셋**: 서식·배경·출력 규격·출처 배치 설정을 현재 브라우저의 IndexedDB에 보관합니다. 사용 중인 직접 등록 폰트도 보관합니다. 원문·출처 내용·인물 이미지·개별 문단 서식은 제외합니다. 이름을 지정해 저장·불러오기·덮어쓰기·삭제할 수 있습니다.

너비 320–1,800px, 페이지 높이 최대 12,000px, 내용 30,000자, 문단 1,500개, 최대 100페이지를 지원합니다. 배경은 PNG/JPG/WEBP 15MB·4천만 픽셀 이하이며 긴 변 2,400px로 축소해 사용합니다. 일괄 PNG 생성은 합계 200MB까지 지원합니다. 직접 등록 폰트는 파일당 15MB, 최대 20개입니다. 범위를 초과하거나 본문 영역이 부족하면 저장을 중단하고 조정 방법을 표시합니다.

## SYS.PROFILE

원래 `index.html`의 프로필 화면은 `profile.html`로 이동했으며, `style.css`, `fonts.css` 및 기존 프로필 동작을 유지합니다. 글꼴·테마 목록만 `profile-presets.js`로 분리하여 두 도구가 공유합니다.

- 가로형 / 세로형 자기소개표, 기존 테마·개별 색상 설정
- 미리보기 텍스트 직접 편집과 항목별 글꼴 크기 조절
- 프로필 이미지, 이미지 칸, 캡션과 스티커 배치
- 기존 2배 해상도 PNG 저장과 `MADE BY @COLT` 표기

## 파일 구성과 확장

- `index.html`, `chamber.css`, `chamber.js`: 홈과 상단 탐색, 해시 주소에 따른 모듈 전환
- `profile.html`, `app.js`, `style.css`: 기존 프로필 메이커
- `excerpt.html`, `excerpt.css`, `excerpt.js`: 발췌 편집 화면·상태·내보내기
- `excerpt-core.js`: 지문/대사 파서, 문자 단위 서식·장평 측정, 페이지 계산, 공통 Canvas 렌더러
- `profile-presets.js`, `fonts.css`, `favicon.svg`: 공유 프리셋·글꼴·스코프 아이콘
- `tests/excerpt-core.test.cjs`: 자동 분리, 글자 보존, 페이지 경계, 서식 우선순위 테스트

새 도구는 홈 카드와 상단 링크, iframe 영역을 추가하고 `chamber.js`의 허용 경로와 모듈 목록에 등록하면 됩니다. 각 편집기의 스타일과 상태는 iframe 내부로 분리되어 있습니다.

## 검증

Node.js 18 이상에서 추가 설치 없이 실행합니다.

```sh
node --test tests/excerpt-core.test.cjs
```

자동 테스트는 지문·대사 분리, 글자 보존, 페이지 경계, 메타데이터 영역과 서식 우선순위를 검사합니다. 미리보기와 PNG 출력은 동일한 Canvas 렌더러를 사용합니다.

모든 텍스트·이미지는 브라우저 안에서 처리합니다. 런타임 외부 스크립트, 분석 도구, 서버 API는 사용하지 않습니다. 웹폰트는 기존처럼 jsDelivr와 Google Fonts에서 불러옵니다. 사용자 등록 폰트는 서버로 전송하지 않습니다. 글꼴의 실제 이용 범위는 각 원저작자의 라이선스를 확인해야 합니다.

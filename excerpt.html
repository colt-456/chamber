발췌 데이터 편집 및 출력.

  1. 텍스트 입력

    모바일에서는 패널 상단 손잡이를 위아래로 끌어 높이를 조절합니다. 입력 시 패널이 자동 확장되며, 복귀 버튼으로 미리보기를 다시 표시합니다. TEXT 패널에 원문을 붙여넣으십시오. *지문*, “대사”, 인물명: 대사를 자동 분류합니다. 표시 없는 문장은 기본 분류를 지정하고 문단별로 수정하십시오. 입력란 바로 위의 휴지통은 전체 내용 삭제, 클립보드 버튼은 새 원문으로 덮어쓰기를 실행합니다.

  2. 글꼴과 서식

    FONT 탭에서 본문 글꼴·크기·장평·자간을 지정합니다. 기본 크기는 12pt입니다. 지문·대사·인물·문단별 서식과 선택 글자 형광펜을 지원합니다. 미리보기의 문단을 누르면 바로 수정할 수 있습니다. 글자 범위를 선택하고 상단 도구에서 색상·굵게·이탤릭·취소선·밑줄·형광펜을 지정하십시오. ✓ 또는 Esc로 직접 편집을 종료합니다.

  3. 출처와 채팅형

    TEXT 하단에서 제목·제작자·캐릭터·플랫폼·출처의 모서리 위치와 글꼴·색상을 지정합니다. 채팅형은 상단에서 선택하십시오. THEME 탭에서 대사창 색상·형상·인물 이미지를 설정합니다.

  4. 배경과 저장

    THEME 탭에서 배경 이미지·밝기·불투명도·프레임을 지정합니다. OUTPUT 탭에서 자동 높이·고정 규격·4장 분할을 선택합니다. 저장 파일은 개별 PNG이며, 제작 도구의 이름·도메인·제작자 표기는 삽입하지 않습니다.

  5. 프리셋

    현재 브라우저에 서식·배경·출력 규격을 저장합니다. 원문과 출처는 저장하지 않습니다. 새로고침 전 PNG를 출력하십시오. 다중 다운로드 차단 시 OUTPUT 목록에서 각 파일을 저장하십시오.

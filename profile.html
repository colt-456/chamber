미리보기에서 바로 작성합니다.

  1. 텍스트 편집

    이름, 소개, 장르, INFO, NG, 이미지 캡션을 누르면 입력창이 나타납니다. 첫 편집 시 샘플이 지워지며, 이후에는 작성한 내용이 유지됩니다.

  2. 글꼴과 크기

    Font 탭에서 모든 입력 내용의 글꼴을 바꿉니다. User Font에서 글꼴 파일을 등록하면 즉시 적용되며 위 글꼴 목록에서도 선택할 수 있습니다. 크기는 선택한 텍스트에 px 단위로 적용되며, 전체 내용에 적용할 수도 있습니다.

  3. 태그와 이미지

    성향 태그는 미리보기에서 누릅니다. ＋ 버튼으로 직접 태그를 추가합니다. 이미지와 스티커는 드래그·휠로 배치합니다.

  4. 저장

    PNG 저장은 글꼴 로딩 후 2배 해상도로 진행됩니다. 편집 테두리는 출력되지 않습니다. 새로고침하면 작업 내용이 초기화됩니다.

본 웹사이트는 D2Coding, 나눔고딕코딩, Orbit, 엘리스 디지털 배움체, Intel One Mono, 구름 산스 코드, Mona 폰트를 사용하고 있습니다.

글꼴 이용 및 사용자 등록 안내

무료로 제공되는 글꼴도 이용 범위는 라이선스에 따라 다릅니다. 이미지 제작·상업적 이용·배포 등 사용 목적에 맞는 권한을 확인하십시오. 각 글꼴의 저작권과 라이선스는 원저작자에게 있습니다.

  • D2Coding / NAVER
  • 나눔고딕코딩 / NAVER
  • Orbit / JAMO
  • 엘리스 디지털 배움체 / 엘리스
  • Intel One Mono / Intel
  • 구름 산스 코드 / 구름
  • Mona / MonadABXY

직접 등록하는 폰트는 사용 권한을 확보한 파일로 한정합니다. 등록 파일은 서버로 전송되지 않으며 현재 브라우저에서만 사용합니다. 등록 폰트는 새로고침하거나 페이지를 닫으면 초기화됩니다.

본 서비스는 사용자가 직접 등록한 폰트의 라이선스를 확인하거나 보증하지 않습니다. 해당 폰트의 이용 권한 확인과 사용으로 발생하는 저작권 문제의 책임은 사용자에게 있으며, 서비스 제작·배포자는 사용자 등록 폰트의 무단 사용으로 발생하는 분쟁에 책임을 지지 않습니다.
